# FILE-only control/stop interface comparison

Scope CLOSED/STOP after the hash seal and terminal closure. No native implementation, compilation, guest, producer import, binary/firmware/RAM, device, DBus, Bluetooth or audio operation.

The comparison supplies all public eight API names/signatures/order and old ten adapter roles. Under the explicitly assumed ARM32 four-byte pointer/type layout they are 36B and 40B respectively; these are source derivations, not a compiler or physical ABI validation. Bind exact typed symbols if their final image retention/mode/residency is established. Do not cast either table.

The coordinator view and both reviewed coordinators have the same fifteen fields (60B in that source model). Continuous native source/anchor retirement and finite ticket/rearm/release semantics differ. Same size does not make the whole family interchangeable.

The key missing binding is a durable native anchor/node-generation token mapped to controller generation, session/ownership epochs, Source actor and ownership cookie. Current registration_ticket is a bootstrap audit seed; old publication captured a live FIFO ticket. Started and complete-return cleanup notifications need the same persistent identity. Request acceptance is not process completion or STOP_DONE.

Core generation/admission/lease logic and stop predicate can be reused. Typed cancel/observe providers, causally matched native iteration, wake-to-controller service, full original return leases and future callback exclusion remain unproved. Nothing here implements these providers or installs hooks.

Fresh reads: three fixed C files, 17,119B. Ten own prior complete captures (113,290B) were reused in session memory, with no fresh stat/hash claim. Filename index I/O is separately disclosed and unmeasured. All line references bind whole-source SHA values. Source bodies are not recopied.

The prior sync guard capture includes music_session_guard_v4.h at line 5, not the base .c. Its exact old capture pin is retained in source-pins.json. Earlier source scopes and native failed/unexecuted evidence are unchanged.

Artifacts: comparison.json, proof.json, source-pins.json, actual-read-receipts.json, sealed-files.json and post-seal actual-terminal-closure.json. The seal uses emitted artifact bytes plus final size/mode/stat; it is not independent native or image readback. Native ownership, STOP_DONE, App/direct phone/speaker/install acceptance remain false.
