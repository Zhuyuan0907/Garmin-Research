Usage: osmium getid [OPTIONS] OSM-FILE ID...
       osmium getid [OPTIONS] OSM-FILE -i ID-FILE
       osmium getid [OPTIONS] OSM-FILE -I ID-OSM-FILE

Get objects with given ID from OSM file

COMMAND OPTIONS:
  --default-type arg (=node)  Default item type
  -i [ --id-file ] arg        Read OSM IDs from text file
  -I [ --id-osm-file ] arg    Read OSM IDs from OSM file
  -H [ --with-history ]       Make it work with history files
  -r [ --add-referenced ]     Recursively add referenced objects
  -t [ --remove-tags ]        Remove tags from objects not explicitly requested
  --verbose-ids               Print all requested and missing IDs

COMMON OPTIONS:
  -h [ --help ]               Show usage help
  -v [ --verbose ]            Set verbose mode
  --progress                  Display progress bar
  --no-progress               Suppress display of progress bar

INPUT OPTIONS:
  -F [ --input-format ] arg   Format of input file

OUTPUT OPTIONS:
  -f [ --output-format ] arg  Format of output file
  --fsync                     Call fsync after writing file
  --generator arg             Generator setting for file header
  -o [ --output ] arg         Output file
  -O [ --overwrite ]          Allow existing output file to be overwritten
  --output-header arg         Add output header

Use 'osmium help getid' to display the manual page.
