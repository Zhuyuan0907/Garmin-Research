安裝在樹莓派執行，Garmin需接USB並進入隨身碟模式。在解壓後的本包目錄：
  python3 install_native_house_supplement.py
預設唯讀確認。已授權的安裝／還原命令：
  sudo python3 install_native_house_supplement.py --install
  sudo python3 install_native_house_supplement.py --rollback

工具僅接受原已授權的2565RT/HWID1352/8.00及精確USB、單機與磁碟身份。它只替換.System/gmapprom1.img，保護原廠其他圖層、語音、原JAI、授權及資料庫；要求已安裝的Search v2道路圖雜湊一致。包內roadmap檔供配套保留，安裝工具本身不另寫道路圖或韌體。
