保守條件：
  House key 僅正 ASCII integer / 之正subnumber＋號；不猜 hyphen 是之號或範圍。
  臺→台／NFKC／外側空白僅主機 exact matching，不改裝置 prefix comparator。
  現有 primary_ref 證明可使用同文字 ref，不能證明該街已有此地址。
  坐標僅 global finite WGS84 bounds，未通過台灣/城市 polygon 或路由位置驗證。
  同一 native street+house 的任何 source conflict / unready member 使整 key 進 review；
  多個 ready members 的 Decimal 正規座標不同則標 cross-group coordinate collision。
  相同座標的 multiple groups 保留各 group 與 source IDs；後續 writer 須先 coalesce provenance，
  不得把 repeated planning groups 當不同的新門牌。
