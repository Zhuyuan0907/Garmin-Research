# 02 備份與實機操作

## 完整備份

- 2026-10-02 從 USB 隨身碟模式取得整個邏輯磁碟映像（3,879,731,200 bytes），
  SHA-256 `df393136d4d14dd31906c1f161fc354cb097c56e3bf8c2278433d01ca2f1c6e2`。
- FAT 內 1,402 個檔案逐一讀出並比對雜湊。
- 備份**不包含** USB 沒有曝光的 bootloader 區域與行車紀錄器 SD 卡。
- 備份檔含原廠韌體、圖資與單機資訊，所以沒有放進這個 repo。

相關腳本：`scripts/garmin_backup.py`、`scripts/verify_file_backup.py`、`scripts/compact_original_backup_v1.py`。

## 寫入車機的規則

每個安裝腳本都遵守同樣的流程：

1. 以 USB 序號、磁碟大小與 `GarminDevice.xml` 確認是同一台機器、同一個 HWID。
2. 寫入前查即時剩餘空間；替換前把原檔另存。
3. 原子替換、`fsync`、完整讀回比對雜湊。
4. 確認其他原廠檔案沒有變動，再安全卸載。
5. 必須能還原：還原後同樣讀回比對，再請使用者冷開機確認。

主要腳本：

| 腳本 | 用途 |
| --- | --- |
| `scripts/install_taiwan_map.py` | 安裝 OSM 台灣圖 |
| `scripts/install_theme.py` | 安裝自訂地圖主題 |
| `scripts/install_native_audio_test.py` | 放置診斷用 `Garmin/test.wav` |
| `scripts/stage_native_marker_voice.py` | 單檔替換美玲語音包做程式標記測試，可還原 |
| `scripts/stage_native_warm_probe_voice.py` | 唯讀音訊狀態診斷版語音包，可還原 |

## 注意

- 沒有刷寫過 MAIN 或 BOOT；所有改動都是一般檔案層級。
- 任何掛載成 loop、標籤為 GARMIN 的備份視圖都不是實機，不能拿來當作實機狀態。
