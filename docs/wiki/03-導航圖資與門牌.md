# 03 導航圖資與門牌

> 2026-10-07 起依使用者指示停止導航修復；以下是停止時的狀態。

## 圖層

原廠圖資由兩部分組成：CN Taiwan NT2016.11 道路主圖，以及 2016.10 的 Address Point 門牌圖（含 MDR 門牌索引）。
另外 `TWNJAI` 資料庫保存行政區與街道名稱的全文索引。這些原廠檔案沒有放在 repo。

## 自編 OSM 台灣圖

- 以 Geofabrik 台灣全區 OSM 資料，用 mkgmap／splitter 編譯成含路由、索引與繁中標籤的 IMG（`scripts/build_taiwan_map.py`）。
- 實機清單可見「OSM Taiwan 2026-10-01」。
- 單獨使用 OSM 圖時，街道搜尋找不到「民權路」；原廠 CN + Address Point 才能準確搜到。
- 新版 Search v2 修正了縣市邊界歸屬與字重排序（民權／民和混淆），日常使用建議 **Address Point + Search v2** 一起勾選。

## 門牌補充

做法是把 OSM 的門牌點對應到原廠門牌索引，在**既有街道**下追加原本缺少的整數門牌，保留原廠所有記錄與順序。

| 版本 | 內容 | 結果 |
| --- | --- | --- |
| 民權路 9 筆 | 單一街道試驗 | 6／150／184 號搜尋、位置、路線正確 |
| 跨縣市 v2（4K 容器） | 130,637 筆新門牌、18,823 條街 | 道路正常；民權路三筆回歸測試通過 |
| 巷弄 v3（8K 容器） | 再加 58,233 筆巷弄門牌 | **道路圖層消失**，已精確還原 |

v3 同時改了容器大小與索引內容，所以道路消失的原因還沒有分離出來。之後在離線環境做了 4K 封裝、
只改標頭等對照組，以及單筆巷弄的最小差異檔，但都沒有再上機。

幾個重要觀察：

- 原 4K 容器宣告上限 128 MiB；完整 v3 內容約 146 MiB，壓縮可回收的空間仍不足。
- 原廠門牌記錄有子號（之 1、之 2）與交叉路口等特殊分支，不能當成一般數字排序或清除旗標。
- 新增街道（例：台中市北屯區敦富六街）需要同時改 MDR、標籤池與 TWNJAI 全文索引；已做出離線原型，未上機。

## 其他

- 地圖刷新慢、移動時短暫破圖：原廠圖同樣會發生，使用者判斷是機器本身慢，已停止此項測試。
- 原廠 2016 道路與門牌、JCV 路口實景、授權檔都保留，沒有被替換。
